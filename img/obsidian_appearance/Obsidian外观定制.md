# commander 插件 工具定制

适用于**喜欢左侧工具栏，不经常用命令面板**的，对于想把左侧工具栏隐藏的就 ***没有必要了***

插件的主要优势是可以***定制工具图标***

插件市场搜索并下载插件

![](https://cdn.jsdelivr.net/gh/Bastandern/pic_bed@main/img/obsidian_appearance/Obsidian%20%E5%A4%96%E8%A7%82%E5%AE%9A%E5%88%B6_260403_030236.png)

选择命令 → 选择图标 → 保存
图标会显示在左侧工具栏

这里能选择所有在命令面板的命令，包括原生 + 插件
![](https://cdn.jsdelivr.net/gh/Bastandern/pic_bed@main/img/obsidian_appearance/Obsidian%20%E5%A4%96%E8%A7%82%E5%AE%9A%E5%88%B6_260403_030510.png)


# hider 插件 隐藏仓库名

这是一个专门隐藏组件的插件，其中有两项比较特别（其他的 AnuPpucin 大部分都有了）

隐藏了仓库名栏的话，就没有设置图标了，想要打开设置可以通过快捷键 `ctrl+,`

# css 定制

ctrl+shift+I 打开 DevTools
这个 elements 里面全是前端代码
![](https://cdn.jsdelivr.net/gh/Bastandern/pic_bed@main/img/obsidian_appearance/Obsidian%20%E5%A4%96%E8%A7%82%E5%AE%9A%E5%88%B6_260403_031343.png)

组件名称什么的全都在代码里写出来了，如果学过前端可以直接写css去改样式

没学过也没关系，我们找到组件名称后让ai帮忙写代码

点一下这个图标，然后把光标放在你想改样式的组件上
![](https://cdn.jsdelivr.net/gh/Bastandern/pic_bed@main/img/obsidian_appearance/Obsidian%20%E5%A4%96%E8%A7%82%E5%AE%9A%E5%88%B6_260403_031525.png)
