# pic_bed

这是我的个人博客图床与资料归档仓库，主要用于存放博客、B 站视频以及学习笔记中用到的图片和相关静态资源。

## 仓库内容

- `img/`：博客文章、B 站视频中使用的图片和资源。
- `documents/`：北京邮电大学（BUPT）网络空间安全专业 23 级各科资料，以及我的课程笔记。
- `music/`：与博客或视频内容相关的音乐资源。
